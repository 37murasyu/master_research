# 依存の一覧の正本は requirements_min.txt（計測・GUI・解析の実行に要るもの）。ここは古い手順の
# `pip install -r requirements.txt` のための入口で、パッケージを直接並べない（並べると食い違う:
# opencv-python と opencv-contrib-python の二重、mediapipe の版の固定漏れ、PyQt5（GPL）入りで PySide6 無し）。
